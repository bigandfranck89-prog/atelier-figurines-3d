Meshy la sculpte en 3D (boucle de critique) → Franck prépare le fichier .3mf → l'ami imprime (Bambu Lab P2S).

- **Guide complet** : [`docs/GUIDE_DEMARRAGE.md`](docs/GUIDE_DEMARRAGE.md)
